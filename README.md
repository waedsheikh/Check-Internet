# Internet Connectivity Checker

A lightweight, responsive web application built with pure HTML, CSS, and JavaScript to test whether you are currently connected to the internet.

## 🚀 Features

- Real-time Status Detection: Uses the native Web API to detect instant changes in network connectivity.
- Visual Feedback: Clear status indicators showing whether you are Online or Offline.
- Clean UI: Responsive design crafted with modern HTML5 and CSS3.
- Zero External Dependencies: Built with pure vanilla JavaScript (no extra libraries required).

## 🛠️ Built With

* HTML5 - Page structure and semantic elements.
* CSS3 - Styling, layout, and visual indicators.
* JavaScript (ES6+) - Logic for network status monitoring (navigator.onLine and event listeners).
